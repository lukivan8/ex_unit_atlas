# Support

## Usage questions

Start with:

- [Getting Started](docs/getting-started.md)
- [Report format](docs/report-format.md)
- [Current limitations](README.md#current-limitations)

Use GitHub Discussions for usage and design questions when Discussions is
enabled.

## Bug reports

Open a GitHub issue with a minimal reproduction, Elixir and OTP versions, the
expected behavior, and the observed behavior. Follow the bug report template.

## Security issues

Do not use public issues. Follow [SECURITY.md](SECURITY.md).
